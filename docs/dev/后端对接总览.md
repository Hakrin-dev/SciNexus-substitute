# 后端对接总览（前端 → FastAPI）

> 前端视角对接说明，与 `backend/README.md` 互为补充。面向「后端对接与开发」。

## 1. 调用链路

前端统一走 [`lib/api/client.ts`](../../lib/api/client.ts)：

- `API_BASE` 默认空 → 请求落到同源 `/api/*`，即 **Next.js Route Handlers**（`app/api/*/route.ts`，BFF / 代理层）
- 可经构建期 `NEXT_PUBLIC_API_URL` 或运行时 `window.__API_BASE__` 直接指向 FastAPI（默认 `http://localhost:8000`）
- 鉴权：`localStorage["yanshu_token"]` → `Authorization: Bearer <token>`
- 统一响应结构 `ApiResp { success, data, error, code, pagination, meta }`

## 2. 两层后端

| 层 | 位置 | 作用 |
|----|------|------|
| Next.js Route Handlers | `app/api/*/route.ts` | 同源 BFF；部分用服务端 `better-sqlite3` 做本地数据；线上前端容器化时由它们代理到 FastAPI |
| FastAPI | `backend/` | 真实 API + 多智能体；SSE `/api/chat/stream` |

> 字段约定「前端优先」：后端返回字段用前端命名（`tags` / `citations` 数字 / `abbr` 等），视觉字段（颜色 / 徽章 / 倒计时）一律前端派生（[`lib/api/adapters.ts`](../../lib/api/adapters.ts)）。

## 3. 认证

- `POST /api/auth/login` → `{ token, user }`
- `POST /api/auth/register`、`GET /api/auth/me`、`POST /api/auth/logout`
- [`stores/auth.ts`](../../stores/auth.ts) 管理 `token` / `user`；`client.setToken` 写 localStorage
- 待办（见 `PRD-用户系统.md`）：HttpOnly Cookie / 刷新令牌（当前为 localStorage，演示登录 `demoLogin` 在真实接口失败时回退纯前端态）

## 4. Mock 保底策略

- [`lib/api/services.ts`](../../lib/api/services.ts) 的查询 hook：**API 成功用真实数据，失败自动回退 `lib/data/*` mock**（组件接口不变）
- **演示态**（`stores/demo-state.ts`）：课题新建 / 归档 / 删除、AI 记忆条目为纯前端态，不调后端
- 原则：新增真实接口时，先在前端 hook 接真实、保留 mock 作 `placeholderData`，再逐步下掉 `demo-state`

## 5. 演示态 → 真实后端：迁移清单

| 演示态 | 真实端点（规划） | 改动点 |
|--------|------------------|--------|
| 课题新建 / 归档 / 删除 | `POST` / `PUT` / `DELETE /api/projects` | `demo-state` → `services` hook；`demo-state` 作离线缓存 |
| AI 记忆 | `GET` / `PUT /api/memory`、`POST /api/memory/entries` | 见 [长期记忆-开发文档.md](长期记忆-开发文档.md) |
| 科研数据库检索式 | `POST` / `GET /api/database/saved-searches` | 见 [知识库-开发文档.md](知识库-开发文档.md) |
| 笔记 | `POST` / `GET` / `PUT` / `DELETE /api/notes` | 见 [知识库-开发文档.md](知识库-开发文档.md) |

## 6. SSE 流式

- `streamChat()`（[`lib/api/client.ts`](../../lib/api/client.ts)）解析后端 SSE：
  - `event: meta` → 元信息（工作流 / 生成文件）
  - `data: {"choices":[{"delta":{"content":"..."}}]}` → 增量文本
  - `event: done` → 结束
- 用于 `/api/chat/stream`、`/api/translate/stream`

## 7. 本地联调

```bash
# 终端1：前端
pnpm dev            # :3000
# 终端2：后端
cd backend && python -m uvicorn server.main:app --port 8000
# 前端指向后端（二选一）
#   a) .env.local: NEXT_PUBLIC_API_URL=http://localhost:8000
#   b) 浏览器 console: window.__API_BASE__='http://localhost:8000'
```

- 后端不可达时前端自动回退 mock，可离线开发
- LLM 密钥在 `backend/agent/.env`；无密钥走 mock provider（与真实同代码路径）

## 8. 分页 / 错误约定

- 分页：`{ page, page_size, total, total_pages }` 置于 `ApiResp.pagination`
- 错误：`!resp.ok` → 抛 `ApiError(status, code)`；组件用 `toast` 提示 `error`
