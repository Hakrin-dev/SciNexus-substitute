# 知识库 后端对接（笔记 / 科研数据库 / 记忆）

> 配套：[PRD-知识库.md](../prd/PRD-知识库.md)、[PRD-长期记忆.md](../prd/PRD-长期记忆.md)；总览见 [后端对接总览.md](后端对接总览.md)

## 1. 现状

- **论文库**：已接后端 `/api/library`（文件夹、条目、进度、批量删），真实可用
- **笔记**：`NotesBoard` 前端组件，无后端；规划见 `PRD-知识库.md`
- **科研数据库**：`DatabaseBrowser` 用 `lib/data/database.ts` mock；规划见 `PRD-知识库.md`
- **记忆**：`MemoryBoard` 用 `stores/demo-state.ts`（前端），规划见 `PRD-长期记忆.md`

## 2. 需新增 / 扩展端点

### 笔记
- `GET    /api/notes?folder=&tag=&keyword=&page=`
- `POST   /api/notes`            `{ title, body, tag_ids, paper_ids, folder_id }`
- `GET    /api/notes/:id`
- `PUT    /api/notes/:id`
- `DELETE /api/notes/:id`
- `GET/POST /api/notes/tags`     标签管理
- `GET/POST /api/notes/folders`  笔记本（可复用 `library/folders` 思路）

### 科研数据库
- `GET    /api/database/saved-searches`      保存的检索式
- `POST   /api/database/saved-searches`      `{ name, query, payload }`
- `PUT/DELETE /api/database/saved-searches/:id`
- （检索本身复用 `/api/search`，不必新端点）

### 长期记忆（详见 [长期记忆-开发文档.md](长期记忆-开发文档.md)）
- `GET  /api/memory?scope=global|project`
- `PUT  /api/memory`            `{ enabled: boolean }` 总开关
- `POST /api/memory/entries`    `{ fact, scope, project_id, source }`
- `PUT/DELETE /api/memory/entries/:id`
- `POST /api/memory/entries/:id/toggle`

## 3. 数据模型（草案）

```ts
Note        { id, user_id, title, body(md), tag_ids[], paper_ids[], folder_id, updated_at }
SavedSearch { id, user_id, name, query, payload(json), created_at }
MemoryEntry { id, user_id, fact, scope: 'global'|'project', project_id?, source, created_at, enabled }
```

## 4. 迁移步骤

1. 后端落地上述端点（`backend/server/main.py` + 序列化 + 数据层）
2. 前端 `services.ts` 增 `useNotes()` / `useSavedSearches()` / `useMemory()` hook，真实优先 + mock 保底
3. `NotesBoard` / `MemoryBoard` / `DatabaseBrowser` 改读 hook，写入经 `apiPost` / `apiPut` / `apiDelete`
4. `demo-state` 仅作离线草稿缓存，登录后合并 / 同步（冲突以后端为准）
5. 移除对 `lib/data/database.ts` 的硬依赖（保留为 `placeholderData`）

## 5. 关联

- 笔记 `paper_ids` → `/api/papers/:id`（跳转）
- 数据库结果 → `library.add` 收藏（已有端点）
- 记忆 `project_id` → `/api/projects/:id`（项目级作用域）

## 6. 待定

- 笔记编辑器（TipTap）的 `body` 存储格式
- 检索式 `payload` 结构（过滤条件序列化）
- 记忆抽取服务在 `backend/agent` 的落点
