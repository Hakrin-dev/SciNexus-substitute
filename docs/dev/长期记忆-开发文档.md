# 长期记忆 后端对接（AI Memory）

> 配套：[PRD-长期记忆.md](../prd/PRD-长期记忆.md)；与 [知识库-开发文档.md](知识库-开发文档.md) 并列；总览见 [后端对接总览.md](后端对接总览.md)

## 1. 现状

- 前端 `MemoryBoard`（`components/features/knowledge/memory-board.tsx`）+ `MemoryMasterToggle` 已就位
- 状态全部在 `stores/demo-state.ts`：`memoryEnabled`（总开关）、`memoryEntries`（条目，含 `scope` / `source` / `createdAt` / `off` 映射）、`memoryOff` / `toggleMemoryEntry` / `deleteMemoryEntry`
- **后端已上线（2026-08-31）**：`/api/memory` 系列端点由 Next.js Route Handlers（SQLite 持久化）与 FastAPI 双实现；`MemoryBoard` / `MemoryMasterToggle` 已接真实接口，未登录/后端不可达时回退 demo-state（仅作离线缓存）

## 2. 需新增端点

- `GET  /api/memory?scope=global|project`  拉取当前用户记忆条目（含总开关状态）
- `PUT  /api/memory`                        `{ enabled: boolean }` 全局总开关
- `POST /api/memory/entries`                `{ fact, scope, project_id?, source }` 新增（手动 / agent 自动）
- `PUT  /api/memory/entries/:id`           编辑 `fact`
- `DELETE /api/memory/entries/:id`         删除
- `POST /api/memory/entries/:id/toggle`    启用 / 停用单条

## 3. 数据模型（草案）

```ts
MemoryEntry {
  id: string
  user_id: string
  fact: string
  scope: 'global' | 'project'
  project_id?: string
  source: string        // 如 "对话-2026-08-27" / "手动"
  created_at: string
  enabled: boolean
}
MemorySettings { user_id, enabled: boolean }
```

## 4. 迁移步骤

1. ✅ 后端端点已落地：Next.js Route Handlers（`app/api/memory/**`，SQLite 表 `memory_settings` / `memory_entries`）+ FastAPI（`server/main.py`，进程内存储）
2. ✅ `useMemory()` / `useSetMemoryEnabled()` / `useToggleMemoryEntry()` / `useDeleteMemoryEntry()` 已加入 `services.ts`
3. ✅ `MemoryBoard` / `MemoryMasterToggle` 已改读 hook，总开关经 `PUT /api/memory`；知识库首页计数同步接入
4. `demo-state` 的 `memoryEntries` 仅作离线缓存 / 未登录只读，登录后合并（以后端为准）
5. 自动写入：对话结束由 agent（supervisor → synthesis / critic）提取事实，调用 `POST /api/memory/entries` 入库

## 5. 与 agent 的联动

- 对话开始时，后端按 `(user_id[, project_id])` 注入启用中的记忆到 system prompt
- 写入异步，不阻塞对话；critic 校验防幻觉（不静默丢失、不编造）

## 6. 验收（与 PRD 对齐）

- 开启 → 对话提偏好 → 条目出现 → 刷新仍在
- 关闭总开关 → agent 不再引用记忆
- 项目级记忆仅在该项目工作台可见 / 生效
