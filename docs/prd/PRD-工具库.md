# PRD-工具库：MCP / 技能 / 插件

> 关联开发文档：[工具库-开发文档.md](工具库-开发文档.md)

## 1. 背景

工具库当前为前端静态展示（`skills-board` / `mcp-guide` / `plugins-board`）。MCP 页已有「我的服务器 / 配置说明」双标签页，但无真实连接；技能 / 插件为占位。目标是把工具库变为可管理的「能力市场 + 我的连接器」，让高级用户接入自己的 MCP server，并让 agent 真正能调用这些能力。

## 2. 目标

- **MCP**：用户接入自己的 MCP server（URL / 命令），查看可用工具、连接状态，供 agent 调用
- **技能**：后端技能注册 / 市场，已安装与可发现
- **插件**：扩展点框架（翻译 / 绘图 / 文献管理 等）

## 3. 范围

### MCP
- 新增 / 编辑 MCP server 配置（`name`、`transport` stdio/sse、`command`/`url`、`env`、`header`）
- 连接测试与健康状态
- 列出该 server 暴露的工具（`tools/list`）
- 启用 / 停用某个 server（对 agent 可见性）

### 技能
- 技能列表（后端注册）、分类、详情、安装 / 卸载
- 启用 / 停用

### 插件
- 插件清单、启用 / 停用、配置

## 4. 用户故事

- 作为高级用户，我把自己的 arXiv MCP server 接进来，让 AI 能直接查最新预印本。
- 作为用户，我从技能市场装一个「文献综述」技能并启用。
- 作为用户，我禁用某个插件后，相关能力从 AI 工具集中移除。

## 5. 功能需求

- **T1** MCP server CRUD + 连接测试
- **T2** 工具清单拉取与缓存（`tools/list`）
- **T3** 启用 / 停用（影响 agent 工具集）
- **T4** 技能市场浏览 / 安装 / 卸载 / 启用
- **T5** 插件管理与配置
- **T6** 密钥安全存储（后端加密，不落前端）

## 6. 非功能需求

- MCP 连接状态轮询 / 事件，失败明确报错
- 密钥仅后端可见，前端仅填不读回明文
- 多用户隔离（server 配置按 `user_id`）

## 7. 验收标准

- 新增 MCP server → 测试通过 → 工具出现在 agent 可调列表
- 技能安装后在对应场景可用
- 禁用后 agent 不再调用该能力

## 8. 待定

- agent 如何动态加载 MCP 工具（`backend/agent` 改造）
- 技能与插件的数据模型、与前端组件（翻译 / 绘图）的映射
- 技能市场的内容来源（官方内置 vs 用户上传）
