## 1. 背景与目标

深知是面向科研人员的 AI 研究平台。当前前端原型已实现完整的用户系统交互(登录弹窗、找回密码页、设置页),但全部为前端演示逻辑(点击登录即成功,用户名为写死的「韩凯润」),**没有任何真实后端支撑**。

本 PRD 定义用户系统的完整产品需求,供系统平台开发人员实现真实的注册、登录、找回密码、账号管理与通知偏好能力。

### 1.1 目标

- 用户可通过「账密登录 / 验证码登录 / 注册」三种方式进入平台;
- 忘记密码的用户可通过「用户名 + 账号 + 验证码」自助重置密码;
- 登录态全站生效,侧边栏用户卡片实时反映登录/未登录状态;
- 用户可在设置页管理个人资料、账号信息、关联第三方账号、语言、外观与通知偏好;
- 未登录用户可浏览公开内容,涉及个人数据的操作(收藏、关注、项目、对话保存)需登录。

### 1.2 非目标(本期不做)

- 企业/机构 SSO 单点登录;
- 实名认证与学者主页认领(仅预留「互动消息」通知入口);
- 会员支付与订阅扣费(订阅 Tab 为占位,另立 PRD);
- 多端登录踢下线管理(仅要求 token 机制可扩展支持)。

## 2. 角色与使用场景

| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 访客(未登录) | 首次访问平台的科研人员 | 低门槛注册;先浏览后决定 |
| 注册用户 | 已有账号的研究者/学生 | 快速登录;跨设备同步个人数据 |
| 忘记密码用户 | 记得用户名和邮箱/手机号,忘记密码 | 自助找回,不依赖人工客服 |

## 3. 功能需求

### 3.1 登录弹窗(全局)

**入口**:侧边栏底部用户卡片(未登录态显示「未登录」+ 用户图标),点击弹出登录弹窗。弹窗为模态层,遮罩点击、右上角 ×、`Esc` 键均可关闭。

弹窗含三个 Tab,默认选中「账密登录」:

#### 3.1.1 Tab 1:账密登录

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 账号/用户名 | 文本 | 是 | 支持用户名、邮箱、手机号三种格式,后端自动识别 |
| 密码 | 密码 | 是 | 8–64 位,不限制字符类型(强度提示见 3.1.3) |

- 「忘记密码?」链接:点击关闭弹窗并跳转 `/reset-password`(独立整页);
- 点击「登录」:前端校验非空 → 调用登录接口 → 成功后关闭弹窗、更新全局登录态;
- 失败时在表单上方展示错误提示(见 §6 错误码),密码不清空,连续失败 5 次锁定 10 分钟。

#### 3.1.2 Tab 2:验证码登录

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 邮箱/手机号 | 文本 | 是 | 邮箱格式或中国大陆手机号(1[3-9]\d{9}) |
| 验证码 | 文本 | 是 | 6 位数字 |

- 「获取验证码」按钮:点击后调用发送验证码接口,进入 60s 倒计时,倒计时期间按钮禁用并显示「重新发送(59s)」;
- 同一账号 1 分钟内只能发 1 条,单天上限 10 条;
- 验证码有效期 10 分钟,错误 5 次作废;
- **该账号未注册时,验证码登录成功后自动创建账号并进入「完善资料」引导**(用户名默认取邮箱前缀/手机号掩码,可修改)。

#### 3.1.3 Tab 3:注册

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 用户名 | 文本 | 是 | 2–20 字符,中文/英文/数字/下划线,全站唯一(不区分大小写) |
| 账号 | 文本 | 是 | 邮箱或手机号,全站唯一,未被封禁 |
| 验证码 | 文本 | 是 | 同 3.1.2 规则 |

- 注册成功后**自动登录**并关闭弹窗;
- 密码在注册后可在设置页补设(本期注册流程不含密码字段,与原型一致);
- 用户名重复、账号已注册时,字段下方红字提示。

### 3.2 找回密码页 `/reset-password`

独立整页(无侧边栏),顶部为品牌 Logo + 「找回密码」标题 + 副标题「验证账号身份后即可重置密码」。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 用户名 | 是 | 与注册时一致 |
| 账号 | 是 | 邮箱或手机号,须与用户名匹配同一账号 |
| 验证码 | 是 | 同 3.1.2 规则,发送至该账号绑定邮箱/手机 |
| 新密码 | 是 | 8–64 位,至少含字母+数字,不得与近 3 次历史密码相同 |
| 确认新密码 | 是 | 与新密码一致 |

- 「重置密码」成功 →  toast 提示「密码已重置,请重新登录」→ 跳转回首页并自动打开登录弹窗(账密 Tab);
- 该账号所有已签发 token 全部作废(强制重新登录);
- 底部「← 返回登录」链接回首页;
- 用户名与账号不匹配时,统一提示「用户名与账号不匹配」(不泄露哪个字段错,防账号枚举)。

### 3.3 登录态与用户卡片

- 登录态全局生效,刷新页面保持(持久化);
- **未登录态**:侧边栏底部显示灰色用户图标 + 「未登录」,点击打开登录弹窗;
- **已登录态**:显示圆形头像占位(用户名首字)+ 用户名,右侧「···」按钮;点击「···」向上弹出菜单,含「登出」项;点击遮罩外区域或 `Esc` 关闭菜单;
- 登出:调用登出接口作废服务端 token → 清除本地登录态 → 用户卡片回到未登录态,**不刷新页面**;
- 侧边栏折叠为图标栏时,用户卡片缩为圆形头像按钮,交互相同;
- token 过期(401)时:静默跳转未登录态,下次打开登录弹窗时提示「登录已过期,请重新登录」。

### 3.4 设置页 `/settings`

URL 参数 `?tab=` 控制当前 Tab,与侧边栏「设置」悬停菜单七项一一对应:**个人 / 订阅 / 用量统计 / Agent设置 / MCP / API / 通知**。本 PRD 覆盖「个人」与「通知」两个 Tab;订阅、用量、API 为占位(另立 PRD),Agent 设置与 MCP 见 AI 相关文档。

#### 3.4.1 个人 Tab

四个分区:

1. **简介**:简历式学者画像卡片(照片位 3:4 证件照比例、主要成就列表、主要生平段落)。
   - 照片:支持上传 JPG/PNG,≤5MB,裁剪为 3:4;
   - 成就:用户可添加/编辑/删除条目(标题 ≤30 字 + 说明 ≤60 字),最多 10 条,支持拖拽排序;
   - 生平:多段落富文本,每段 ≤500 字。
2. **账户**:
   - 用户名:可修改,30 天内仅可改 1 次,唯一性校验同注册;
   - 账号:显示当前绑定邮箱/手机号;更换绑定需先验证码验证新账号;
   - 密码:已设密码显示 `••••••••`,点击修改走「验证码验证 + 新密码」流程(同找回密码的规则);未设密码(验证码注册用户)显示「去设置」;
   - **关联账号**:Google Scholar、Hugging Face、GitHub、Google、Apple 五个第三方,每项显示「已关联/未关联」状态与「关联/解除关联」按钮;关联走 OAuth 跳转;解除关联需二次确认;至少保留一种登录方式(唯一登录方式不可解除)。
3. **语言**:中文 / English 单选,切换后全站文案即时切换(本期仅 UI 语言,不含内容翻译)。
4. **外观**:日间 / 夜间 / 跟随系统 三选一,即时生效并本地持久化(已实现,见开发文档)。

#### 3.4.2 通知 Tab

四类通知,每类一张卡片:图标 + 主标题 + 副标题 + 开关 + 展开/折叠详情。

| 类型 | 副标题(原型文案) | 触发场景 |
| --- | --- | --- |
| 动态通知 | 你关注/收藏的学者/机构的动态通知 | 关注的学者发新论文、收藏的机构发新动态 |
| 订阅消息 | 你的订阅和用量统计消息 | 月度用量统计完成、订阅到期提醒 |
| 互动消息 | 与你互动的消息 | 学者认领你关注的主页、你的收藏被推荐 |
| 系统通知 | — | 平台维护、版本公告 |

- 开关即时生效,关闭后该类通知不再推送(站内信与邮件均停);
- 通知投递渠道(站内信/邮件/推送)本期默认站内信,渠道粒度另立 PRD。

### 3.5 未登录访问控制

| 能力 | 未登录 | 已登录 |
| --- | --- | --- |
| 浏览发现页 Feed、搜索、查看论文/学者/机构详情 | ✅ | ✅ |
| 点赞 / 收藏 / 关注学者 / 收藏机构 | 点击时弹出登录弹窗,登录成功后**自动完成原操作** | ✅ |
| AI 搜索 / AI 助手对话 | 可发起,但会话不保存、每日限 3 次 | ✅ 会话保存,配额见订阅方案 |
| 科研项目 / 投稿 / 历史 | 弹出登录弹窗 | ✅ |
| 设置页 | 弹出登录弹窗 | ✅ |

## 4. 交互细节(与原型对齐)

1. 登录弹窗三个 Tab 切换不保留已输入内容(演示行为,实现时保留同 Tab 内容、跨 Tab 清空即可);
2. 所有输入框失焦校验、提交时整体校验,错误提示在对应字段下方红字;
3. 登录/注册/重置按钮点击后进入 loading 态(禁用 + 文案不变),接口返回前不可重复点击;
4. 弹窗打开期间禁止背景滚动;
5. 所有错误提示文案见 §6,文案语气:简短、不指责用户、不暴露系统内部信息。

## 5. 非功能需求

- **性能**:登录/注册/验证码接口 P95 ≤ 800ms;设置页保存 P95 ≤ 500ms;
- **安全**:
  - 密码 bcrypt(cost ≥ 10)哈希存储,任何接口与日志不得出现明文密码;
  - 验证码 6 位随机数字,有效期 10 分钟,错误 5 次作废,发送频控见 3.1.2;
  - 登录接口防爆破:同 IP 每小时 ≤ 30 次尝试,同账号连续失败 5 次锁 10 分钟;
  - 防账号枚举:找回密码、注册时对「账号已存在/不存在」的响应时间与文案一致化;
  - 全站 HTTPS;token 机制见开发文档;
- **合规**:注册即视为同意《用户协议》《隐私政策》(弹窗底部加勾选项,原型未含,实现时补充在注册 Tab 按钮上方);
- **埋点**:登录弹窗曝光、各 Tab 登录成功率、验证码发送成功率、找回密码完成率、登出。

## 6. 错误码与提示文案

| 场景 | 用户提示文案 |
| --- | --- |
| 账号或密码错误 | 账号或密码不正确 |
| 账号被锁定 | 尝试次数过多,账号已锁定,请 10 分钟后再试 |
| 验证码错误/过期 | 验证码不正确或已过期,请重新获取 |
| 验证码发送过频 | 发送太频繁,请稍后再试 |
| 用户名已存在 | 该用户名已被使用,换一个试试 |
| 账号已注册 | 该账号已注册,可直接登录 |
| 用户名与账号不匹配(找回密码) | 用户名与账号不匹配 |
| 两次密码不一致 | 两次输入的密码不一致 |
| 密码不合规 | 密码需 8–64 位,且同时包含字母和数字 |
| 网络/服务异常 | 网络异常,请稍后重试 |

## 7. 验收标准(摘要)

1. 三种登录方式均可完成,登录后侧边栏用户卡片显示用户名首字头像 + 用户名,刷新保持;
2. 验证码 60s 倒计时、频控、错误作废逻辑生效;
3. 找回密码全流程可走通,重置后旧 token 失效;
4. 登出后回到未登录态,个人数据操作重新要求登录;
5. 未登录点击收藏 → 弹登录 → 登录成功后该论文自动收藏;
6. 设置页用户名/账号/密码修改、第三方关联、语言、外观、通知开关全部生效并持久化;
7. 错误提示文案与 §6 一致,不出现系统内部报错原文。
