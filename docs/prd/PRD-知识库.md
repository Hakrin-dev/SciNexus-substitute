# PRD-知识库：笔记与科研数据库（演示态 → 真实后端）

> 关联开发文档：[知识库-开发文档.md](知识库-开发文档.md)；关联 PRD：[PRD-长期记忆.md](PRD-长期记忆.md)、[PRD-工具库.md](PRD-工具库.md)

## 1. 背景与目标

知识库当前含「论文库」（已接后端 `library`）、「笔记」「记忆」「数据库」四页，其中笔记 / 记忆 / 数据库为**纯前端演示态**（`stores/demo-state.ts`、`lib/data/database.ts`），不持久化、不跨设备、不可被真实 agent 读取。

本 PRD 规划将「笔记」与「科研数据库」落地为真实后端能力，使知识资产可在多端同步、可检索、可关联论文，与已上线的论文库形成闭环。

## 2. 范围

### 2.1 笔记（Notes）
- 富文本 / Markdown 笔记的 CRUD
- 标签筛选、全文检索
- 关联论文（引用 `paper_id`，跳转论文详情）
- 笔记本 / 文件夹分组
- 跨设备同步（后端持久化）

### 2.2 科研数据库（Research Database）
- 跨库统一检索（对接后端 `/api/search` + 各专业库适配器）
- 检索式保存、历史、收藏
- 结果导出（引用 / CSV）
- 与论文库、笔记打通（收藏到 `library`、引用到笔记）

> 说明：AI 记忆（长期记忆）为独立数据源（AI 自动积累），见 [PRD-长期记忆.md](PRD-长期记忆.md)，不在本 PRD 范围内，但在「知识库」导航中并列。

## 3. 用户故事

- 作为研究者，我希望把阅读心得写成笔记并打标签，以便日后按主题回溯。
- 作为研究者，我希望笔记能关联某篇论文，以便上下文留痕。
- 作为研究者，我希望保存常用检索式，以便周期性追踪新文献。

## 4. 功能需求

### 笔记
- **N1** 创建 / 编辑 / 删除笔记（Markdown 或块编辑器）
- **N2** 标签管理（多选、新建、按标签过滤）
- **N3** 关联论文（选择 `paper_id`，展示来源徽章，点击跳 `/papers/[id]`）
- **N4** 笔记本 / 文件夹分组与拖拽
- **N5** 全文搜索（标题 + 正文）
- **N6** 列表分页、按最近编辑排序

### 科研数据库
- **D1** 统一检索框（关键词 / 年份 / CCF / 领域），调用 `/api/search`
- **D2** 检索式保存（命名、更新、删除），列表展示
- **D3** 检索历史（按时间）
- **D4** 结果一键收藏到论文库（`library.add`）
- **D5** 引用导出（BibTeX / CSV）

## 5. 非功能需求

- 笔记正文输入本地响应 < 50ms（富文本不卡顿）
- 检索结果首屏 < 1.5s（后端常规 / SSE）
- 数据隔离：按 `user_id`
- 离线：保留本地草稿（可沿用 `demo-state` 作离线缓存层，登录后合并）

## 6. 验收标准

- 新建笔记 → 刷新 → 仍在（后端持久化）
- 笔记关联论文可跳转
- 保存检索式后，在「数据库」页可重新执行 / 删除
- 未登录时给出明确引导（或仅只读本地草稿）
