# PRD-长期记忆（AI Memory）

> 关联开发文档：[长期记忆-开发文档.md](长期记忆-开发文档.md)；关联 PRD：[PRD-知识库.md](PRD-知识库.md)

## 1. 背景

AI 助手在与用户对话时会积累关于用户偏好、研究领域、项目上下文的「长期记忆」，用于个性化回答。当前为前端演示态（`stores/demo-state.ts` 的 `memoryEnabled` / `memoryEntries`），仅在浏览器内有效，切换设备 / 清缓存即丢失，且不可被真实 agent 读取。

UI 已完成：记忆页含总开关（位于「记忆」标题之后）与条目管理（启用 / 停用、删除、全局级 / 项目级筛选）。本 PRD 规划将其后端持久化，并接入真实多智能体。

## 2. 目标

将长期记忆落地为后端持久化的用户级资源，支持**全局级**与**项目级**，由真实多智能体（`backend/agent/`）在对话中读写，实现跨设备、可审计、可管制的长期个性化。

## 3. 范围

- **记忆条目**：`fact`（事实）、`scope`（global / project）、`source`、`createdAt`、`project`（项目级归属）
- **总开关**：全局启用 / 停用 AI 记忆（UI 已置于标题后）
- **单条**：启用 / 停用、编辑、删除
- **作用域**：全局级（所有对话生效）；项目级（仅对应课题工作台会话生效）
- **自动积累**：对话中 agent 提取偏好 / 事实并写入（经 critic 校验防幻觉）
- **隐私**：用户可查看 / 导出 / 清空

## 4. 用户故事

- 作为用户，我希望 AI 记住我的研究领域与偏好，避免每次重复说明。
- 作为用户，我希望关闭记忆后 AI 不再使用历史记忆。
- 作为项目成员，我希望某项目的上下文只在该项目会话中生效。

## 5. 功能需求

- **M1** 总开关（全局）——UI 已就位，对接后端持久化开关
- **M2** 条目列表（全局 / 项目筛选），展示 scope / source / 时间
- **M3** 单条启用 / 停用、编辑、删除
- **M4** 自动写入：对话结束由 supervisor → synthesis / critic 提取事实，经去重 / 置信校验后入库（防幽灵记忆）
- **M5** 导出 / 清空（合规）
- **M6** 项目级记忆在课题工作台会话自动注入 system prompt

## 6. 非功能需求

- 记忆读取延迟 < 50ms（注入上下文）；后端可用 Redis / SQLite
- 写入异步，不阻塞对话
- 隔离：按 `user_id`；项目级按 `(user_id, project_id)`
- 开关关闭时，agent 完全不读取记忆

## 7. 验收标准

- 开启记忆 → 对话中提及偏好 → 条目出现 → 刷新仍在
- 关闭总开关 → AI 回答不再引用记忆
- 项目级记忆仅在该项目工作台可见 / 生效

## 8. 待定

- 记忆抽取由哪个 agent 负责、置信阈值
- 是否支持用户手动「教」AI 记忆（主动写入）
- 记忆与笔记（[PRD-知识库.md](PRD-知识库.md)）的去重 / 关联
